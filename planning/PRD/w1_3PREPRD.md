## 5. 수정 1 — 입력 버퍼 (BOX-12)

### 5.1 원인
지금 상태 머신은 **그 순간의 상태에 규칙이 있는 키만** 받는다. 아래 상태에서는 Space·Shift를 누르면 이벤트가 그냥 버려진다.

| 상태 | 버려지는 키 | 흔한 상황 |
|---|---|---|
| Jump, Fall | Space, Shift | 착지 직전에 다음 점프를 미리 누름 |
| Recover | Space, Shift | 어지러움이 풀리기 직전에 누름 |
| Get | Space | 테이프 줍기가 끝나기 직전에 누름 |
| Slam | Space, Shift | 돌진·복귀가 끝나기 직전에 누름 |
| Idle, Walk | Shift | 테이프에 닿기 직전에 누름 (아직 `near_tape`가 없음) |

### 5.2 동작
- **Space는 "누르고 있는 상태"와 "방금 누름"을 따로 기억한다.**
  - Space 누름: `space_waiting = True`, `space_held = True`, `space_buffer = INPUT_BUFFER_TIME(0.15초)`
  - Space 뗌: `space_held = False`
  - 매 프레임 `space_buffer`를 `frame_time`만큼 줄임 (0 아래로는 안 내려감)
  - Charge에 들어가면 `space_waiting = False` (처리됨)
- **Shift는 "방금 누름"만 기억한다.**
  - Shift 누름: `shift_buffer = INPUT_BUFFER_TIME`
  - 처리되면(Get 또는 Slam에 들어가면) `shift_buffer = 0`
- **땅 위에서 움직일 수 있는 상태(Idle, Walk)**가 되면 매 프레임 아래 순서로 남은 입력을 처리한다.
  1. `space_waiting`이고 `space_held` → **Charge** (차지 시간은 지금부터 셈)
  2. `space_waiting`이고 이미 뗐지만 `space_buffer > 0` → **최소 높이 점프** (Charge를 거쳐 차지 0으로 바로 Jump)
  3. `space_waiting`이지만 둘 다 아니면 → `space_waiting = False` (너무 일찍 눌렀다 뗀 것, 버림)
  4. `shift_buffer > 0`이고 줍기 또는 몸통박치기 조건이 맞음 → **Get / Slam**
- 결과
  - 착지 직전에 Space를 눌러 **누르고 있으면** 착지하자마자 차지가 시작되고, 떼면 뛴다
  - 착지 직전에 Space를 **톡 치면**(0.15초 안) 착지하자마자 낮게 뛴다
  - 테이프에 닿기 0.15초 전에 Shift를 눌러도 닿는 순간 줍는다
- 기존 동작은 바뀌지 않는다: 땅 위에서 Space를 누르면 지금처럼 그 프레임에 바로 Charge

### 5.3 하지 않는 것
- **코요테 타임**(발판을 벗어난 직후에도 점프 허용)은 넣지 않는다. 이 게임의 점프는 "누르고 있다가 떼는" 차지 방식이라, 발판 밖에서 차지를 시작할 수 없다. 대신 발판 끝 근처에서는 5.2의 버퍼만으로 충분한지 플레이로 확인한다.

## 6. 수정 2 — 되돌아가기 (CORE-7)

### 6.1 카메라 양방향
- 화면 안 **따라가기 구간**: 박스의 화면 x가 `CAMERA_BACK_X(400)` ~ `CAMERA_FOLLOW_X(640)` 안이면 카메라는 그대로
  - 박스 화면 x > 640 → 카메라가 오른쪽으로: `camera.x = box.x - 640`
  - 박스 화면 x < 400 → 카메라가 왼쪽으로: `camera.x = box.x - 400`
- `camera.x`는 **0 ~ 맵 오른쪽 끝 - PLAY_RIGHT** 사이로 자른다
- 레벨이 바뀌면(보스 무대) 카메라 범위도 그 레벨 기준으로 다시 잡는다

### 6.2 박스 좌우 한계
- 왼쪽: **맵 왼쪽 끝** `MAP_LEFT + BOX_BB_W/2` (화면 왼쪽 끝 기준이 아님)
- 오른쪽: 맵 오른쪽 끝 - `BOX_BB_W/2` (그대로)
- 되돌아가도 점수는 줄지 않는다 (7.1의 최고 도달 타일 기준). 경비원이 뒤에서 오기 때문에 크게 되돌아갈 수는 없다.

## 7. 새 기능 1 — 점수·해·낮 맵 (DAY-1·2·3, MAP-3)

### 7.1 최고 도달 타일 = 점수
- 지금 타일 번호 = `int((box.x - MAP_LEFT) // TILE_W)` (시작 칸 = 0)
- **최고 도달 타일 `best_tile`** = 지금까지 들어간 타일 번호 중 가장 큰 값. 뒤로 가거나 떨어져도 줄지 않음
- **점수(분) = `best_tile × MINUTES_PER_TILE(10)`**
- 도망친 지 칸 표시: `일 = 분 // 1440`, `시간 = 분 // 60 % 24`, `분 = 분 % 60`
  - 예) 13칸 → 130분 → `0일 2시간 10분`
- 보스 구간에서는 점수가 오르지 않음 (시간 멈춤)
- 잡혀서 처음부터 다시 하면 `best_tile = 0`

### 7.2 낮 맵 61칸
- 건물 1칸 = 10분이므로 낮 10시간(08:00 → 18:00) = **60칸**. 시작 칸을 더해 **61칸**
- `map_data.py`
```python
DAY_PATTERN = ['basic', 'pipe', 'accel', 'gap', 'basic', 'pole']
DAY_MAP = ['start'] + DAY_PATTERN * 10          # 61칸, 마지막 칸 번호 = 60
BOSS_ARENA = ['start', 'start', 'start']        # 임시 보스 무대 (빈터)
```
- 패턴 안에서 `gap`은 항상 `accel` 바로 뒤에 온다 (가속해야 건너는 틈)
- 게임은 `DAY_MAP`으로 시작한다. `TEST_MAP`은 디버그 키(9.6 `M`)로 바꿔 볼 수 있게 남겨 둔다

### 7.3 해 (DAY-2)
- 진행률 `p = best_tile / 마지막 칸 번호(60)` (0 ~ 1)
- 해의 목표 위치: 타원 중심 `(800, 640)`, 가로 반지름 720, 세로 반지름 140
  - `x = 800 - 720·cos(π·p)`, `y = 640 + 140·sin(π·p)` (화면 좌표, 카메라와 상관없음)
- 새 칸에 들어가 목표가 바뀌면 해는 **부드럽게 따라감**: 표시용 진행률 `sun_p`가 `p`를 향해 초당 `SUN_SPEED(0.05)`씩 움직임 (0.05 = 한 칸 1/60보다 충분히 빠름)
- 그림: `ph_sun.png` (96 × 96, 임시) 1배로 그림. 그리기 레이어는 **맵보다 아래, 배경보다 위** (하늘에 있으므로 건물이 해를 가림) → 레이어 `LAYER_SKY`를 BG와 MAP 사이에 추가
- 보스 구간에서는 해를 그리지 않음 (임시 — 4주차에 저녁 하늘로)

### 7.4 낮 끝 (MAP-6, FX-4 임시)
- `best_tile`이 마지막 칸 번호(60)가 되는 순간 **낮 끝**
  1. 경비원이 그 자리에 멈추고 **지친 모습**(임시: 사각형 높이를 절반으로, 바닥에 붙여 그림 = 주저앉음)
  2. 박스는 계속 움직일 수 있음, 잡힘 판정 없음
  3. `DAY_END_TIME(2초)` 뒤 **보스 구간으로 전환**
     - `zone = 'boss'` (지금 칸 `저녁, 공원`, 팁 목록, Shift = 몸통박치기 — B키 전환과 같음)
     - 레벨을 `BOSS_ARENA`로 바꾸고 박스를 `BOX_START_X` 도로 위로, 카메라 0
     - 허수아비를 보스 무대 x `DUMMY_X`(1200)에 둠, 바닥 테스트 테이프는 없앰
     - 생명(테이프 개수)은 그대로 이어짐
     - 점수는 600분(`0일 10시간 0분`)에서 멈춤
- 보스 구간 다음(보스 클리어, 밤)은 4주차. 지금은 R로 처음부터

## 8. 새 기능 2 — 경비원 (CHASE-1·2, UI-4, BOX-11)

### 8.1 경비원 (임시 사각형)
- 그림: `ph_guard.png`를 `GUARD_W(90) × GUARD_H(170)`으로 늘려 그림. 발은 도로 높이(`ROAD_Y`)에 고정
- 시작 위치: 월드 x `BOX_START_X - GUARD_START_GAP(600)` (화면 왼쪽 밖에서 시작)
- 시작 후 `GUARD_START_DELAY(1초)` 동안 기다렸다가 출발
- 이동: **도로만**, 오른쪽으로 `GUARD_SPEED(280)` px/s (박스 걷기 310보다 약간 느림)
  - 박스가 지붕·창틀 위에 있어도 가로로만 쫓아옴
  - 박스를 지나쳐 가지 않음 (잡힘 판정이 먼저 일어남)
- 게임 월드 레이어: ITEM (박스 뒤에 그림)

### 8.2 잡힘 (CHASE-2, BOX-11)
- **거리 = 박스 x - 경비원 x** (가로만, 높이 무관)
- `거리 ≤ CATCH_DIST(90)`이면 잡힘 (지붕 위에서도)
- 잡히면
  1. 박스·경비원이 `CAUGHT_TIME(1초)` 동안 멈춤. 박스는 hit 그림 (1장), 입력 무시
  2. 그다음 **처음부터 다시**: R키 리셋과 같음 + `best_tile = 0`, 해 처음 위치, 경비원 처음 위치, 레벨 `DAY_MAP`, 구간 `chase`
- 낮 끝(7.4) 뒤와 보스 구간에서는 경비원이 멈추고 잡힘 판정도 없음

### 8.3 거리 게이지 (UI-4, 임시)
- 위치: 플레이 칸 오른쪽 위, 가운데 `(GAUGE_X 1420, GAUGE_Y 772)`, 크기 `GAUGE_W(240) × GAUGE_H(18)`
- 배경 `ph_gauge_bg` 위에 채움 `ph_gauge`를 왼쪽 정렬로 그림
- 채움 비율 = `(거리 - CATCH_DIST) / (GUARD_START_GAP - CATCH_DIST)`, 0 ~ 1로 자름 (꽉 차면 안전, 비면 잡힘)
- 보스 구간에서는 그리지 않음 (4주차에 그 자리가 보스 체력바)
- 화면 위 UI 레이어에 그림 (맵에 가려지지 않음)

## 11. 완료 기준 (체크리스트)
### 입력
- [ ] 착지 0.15초 전에 Space를 눌러 누르고 있으면, 착지하자마자 차지가 시작된다
- [ ] 착지 0.15초 전에 Space를 톡 치면, 착지하자마자 낮게 뛴다
- [ ] 회복(어지러움)·줍기·몸통박치기가 끝나기 직전에 누른 Space가 씹히지 않는다
- [ ] 테이프에 닿기 직전에 누른 Shift로 테이프를 줍는다
- [ ] 0.15초보다 훨씬 일찍 톡 친 Space는 무시된다 (착지할 때 저절로 뛰지 않음)
- [ ] 땅 위에서 누른 Space·Shift는 지금처럼 바로 반응한다
### 되돌아가기
- [ ] 왼쪽으로 걸어 왔던 길로 돌아갈 수 있고, 카메라가 왼쪽으로도 따라온다
- [ ] 맵 왼쪽 끝(시작 칸)에서 막힌다
### 경비원
- [ ] 1초 뒤 경비원이 출발해 도로를 따라 쫓아온다
- [ ] 도로에서 계속 걸으면 거리가 조금씩 벌어지고, 테이프를 줍거나 추락해 멈추면 줄어든다
- [ ] 지붕 위에 있어도 가로 거리가 90 이하면 잡힌다
- [ ] 잡히면 1초 멈춘 뒤 처음부터 다시 시작한다 (점수·해·생명 모두 처음)
- [ ] 거리 게이지가 거리에 따라 줄고 늘어난다
### 점수·해
- [ ] 새 건물(타일)에 들어갈 때마다 도망친 지가 10분씩 오른다 (`0일 1시간 0분` = 6칸)
- [ ] 뒤로 가거나 떨어져도 점수가 줄지 않는다
- [ ] 해가 최고 도달 타일에 맞춰 왼쪽 → 오른쪽으로 부드럽게 움직이고, 건물 뒤에 그려진다
### 낮 끝
- [ ] 60칸째에 들어가면 `0일 10시간 0분`, 해가 오른쪽 끝, 경비원이 주저앉는다
- [ ] 2초 뒤 `저녁, 공원` 보스 구간으로 바뀌고, 빈터 무대에 허수아비가 있으며, 생명이 이어진다
- [ ] 보스 구간에서는 점수가 오르지 않고 경비원·게이지·해가 없다
### 기타
- [ ] G·E·M 디버그 키가 동작한다
- [ ] 2주차 기능(발판·추락·멈춤·가속)이 그대로 동작한다
- [ ] 프레임 속도가 달라도 경비원 속도·잡힘 시점·입력 버퍼 시간이 같다
