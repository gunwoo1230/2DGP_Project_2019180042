## 2. PREPRD와 다르게 잡은 부분, 결정한 것

### 결정한 것 (PREPRD에 정해지지 않았던 항목)

| # | 질문 | 결정 |
|---|---|---|
| Q1 | `WALK_SPEED`를 남기나? (§8) | **지움.** 속도는 모두 `FLOOR_SPEEDS`에서 가져옴. 같은 값을 두 곳에 두면 한쪽만 고칠 수 있음 |
| Q2 | 층 번호를 어떻게 구하나? | `box.py`의 `floor_of(y)`: `y + 1` 이하인 `FLOOR_YS` 중 가장 큰 것의 번호 (0 도로, 1 창틀, 2 지붕). 지금 `Jump.enter`의 시작 층 계산과 같은 식이고, 시작 층·기절·속도가 함께 씀 |
| Q3 | 땅 위에서 속도를 정하는 층은? | 지금 발 높이 `floor_of(box.y)`. 발디딤 270·330 → 도로, 450·510 → 창틀, 가속 지붕(570 ~ 630) → 지붕 |
| Q4 | 공중 목표 속도("출발 층의 속도")는 언제 정하나? | `Jump.enter`에서 `box.air_speed = FLOOR_SPEEDS[floor]`. Fall은 Jump에서 이어지므로 같은 값을 씀. 걸어서 벗어날 때도 같음 |
| Q5 | 기절 판단은 어디서? | Fall 규칙의 조건으로: `stunned` = 착지 이벤트이고 `floor > 0`, `착지 y ≤ FLOOR_YS[floor - 1] + 1` → Recover. 아니면 `done_moving` → Walk, `done_stopped` → Idle. Jump에서 착지(같은 층)는 지금처럼 기절 없음 |
| Q6 | 경비원 표시는 어떤 객체인가? | `hud.py`의 `GuardMarker(guard)`, UI 레이어에서 `Hud` 다음에 넣어 테두리 덮개보다 위에 그림. 거리는 그릴 때 `camera.to_screen`으로 계산 |
| Q7 | 깜빡임 시간은 어떻게 재나? | 200px 안에 있는 동안만 `blink_time`에 `frame_time`을 더하고, 밖으로 나가면 0. `int(blink_time / 0.15)`가 짝수면 보임 → 깜빡이기 시작하는 순간은 보이는 상태 |
| Q8 | 잡힘 멈춤 중 표시 | PREPRD대로 규칙 그대로 (화면 밖이면 보임). 맵 시작 근처는 카메라가 0이라 박스가 화면 왼쪽에 있을 수 있어, 잡혀도 경비원이 화면 밖일 수 있음 |

#### C08 `[week1_4] 층 번호 함수` [채움] — §6.1
- `box.py`의 `floor_of(y)` (Q2). `Jump.enter`: `box.floor = floor_of(takeoff_y)`, `box.floor_y = FLOOR_YS[box.floor]`
- 확인: 동작 변화 없음. 임시 `print`로 발디딤 330 → 0, 510 → 1, 가속 지붕 → 2 확인 후 삭제

#### C09 `[week1_4] 한 층 아래 이하로 착지할 때만 기절` [채움] — §6.2

- 기절 시간은 그대로 `(takeoff_y - 착지 y) / 180`
- 확인: §6.3 예시 표 전부 (지붕 → 510·450 기절 없음, → 390 1초, → 330 1.33초, → 도로 2초, 창틀 → 330·270 없음, → 도로 1초, 발디딤 510 → 330 없음, → 도로 1.67초, 도로 층 출발은 없음). 기절 없는 추락도 fall 그림은 보임 (A3)

### M3. 층별 속도 (BOX-13)

#### C10 `[week1_4] 층별 걷기·차지 속도` [채움] — §7.2, §7.3
- `FLOOR_SPEEDS = (310, 330, 350)`
- `Box.floor_speed()` = `FLOOR_SPEEDS[floor_of(y)]` (Q3). `walk_speed()`: 가속 지붕 오른쪽이면 `floor_speed × ACCEL_RATE`, 아니면 `floor_speed`. `charge_speed()`: 가속 지붕이면 `walk_speed()`, 아니면 `floor_speed × 0.4`
- 확인: 도로 310, 창틀 330, 지붕 350, 발디딤 270 → 310, 510 → 330. 차지 124 / 132 / 140, 가속 지붕 525

- `move_in_air`: 목표 속도와 속도 유지 기준을 `air_speed`로. `WALK_SPEED` 삭제 (Q1)
- 확인: 공중에서 반대 방향을 누르면 출발 층 속도를 목표로 천천히 바뀜. 가속 지붕 끝 최대 차지 점프는 gap 지붕에 닿고, 보통 지붕(350)에서는 못 닿음 (2장 위험). 착지하면 새 층 속도
