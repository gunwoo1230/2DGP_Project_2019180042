# 박스야, 도망쳐! — 1주차 PRD (11/4 ~ 11/10)

> 이 문서는 Claude Code에 넘겨 1주차 구현을 진행하기 위한 요구사항 문서입니다.
> 게임 전체 기획은 `구르박스_기획정리_v18.md`, 전체 진행은 `00_전체PRD.md`에 있고, 이 문서는 1주차 범위만 다룹니다.

## 1. 배경

- 과목: 2D 게임프로그래밍 (2019180042 한건우), 최종 발표 12/9
- 언어·엔진: **Python 3 + pico2d**
- 저장소: https://github.com/gunwoo1230/2DGP-2019180042
- 게임 한 줄 요약: 분리수거장에서 탈출한 박스가 경비원(점프맵 추격)과 환경미화원(보스전)에게서 도망치는 가로 스크롤 게임. 아이의 그림일기 콘셉트로, 크레용 스티커 그림을 씀.

## 2. 1주차 목표

**프로젝트 골격 + 박스 조작 4가지(이동, 차지 점프, 테이프 줍기, 몸통박치기)를 평평한 테스트 바닥에서 플레이할 수 있게 만든다.**

### 범위 안

1. 프로젝트 골격: 게임 루프, 모드(play_mode), 게임 월드(레이어·충돌), 상태 머신, 설정값 파일
2. 그림일기 화면: 배경 이미지(`diary_frame.png`) 위에 지금(구간 이름)·도망친 지(0일 0시간 0분 고정) 손글씨, 플레이 칸 왼쪽 위 테이프 생명 칸, 원고지 한 줄에 팁이 바뀌며 한 글자씩 써짐
3. 박스: 서 있기, 걷기(깡충), 차지 점프(모으기·상승·하강), 공중 좌우 약간 조작
4. 테이프: 바닥에 놓인 테이프 줍기 → 연출 → 생명 칸 +1
5. 몸통박치기: 짧은 돌진 + 공격 판정, 테스트용 허수아비
6. 디버그 키: 충돌 박스 보기, 구간(추격/보스) 전환, 리셋

### 범위 밖 (2주차 이후)

- 3층 맵·건물 타일·카메라 스크롤, 발디딤 오르기, 추락 멈춤, 가속 지형
- 경비원, 거리 게이지, 방해 요소(비둘기·창문·물웅덩이), 보스
- 피격(hit)·추락(fall)·회복(recover) 애니메이션 연결 — 그림은 있으나 쓰는 규칙이 2~3주차
- 타이틀·결과 화면, 사운드

## 3. 시작 전에 확인할 것

1. 저장소 구조를 먼저 살펴보고, 기존 실습 폴더와 섞이지 않게 **게임 전용 폴더**(예: `GuruBox/`)를 만든다. 이미 게임 폴더가 있으면 그것을 쓴다.
2. 수업에서 쓰는 `game_framework.py`·`game_world.py`·`state_machine.py` 같은 파일이 저장소에 이미 있으면 **그 구조와 이름을 따른다.** 없으면 아래 4장 구조로 새로 만든다.
3. 함께 받은 묶음(`GuruBox_week1/`)의 `resource/` 폴더, `sprite_data.py`, `font_data.py`, `test_sheet.py`, `test_font.py`를 게임 폴더에 그대로 복사한다. `python test_sheet.py`, `python test_font.py`로 스프라이트·글씨가 제대로 그려지는지 먼저 확인한다.
4. 구현 중 기획과 다르게 해야 할 일이 생기면 임의로 바꾸지 말고 질문한다.

## 4. 폴더·파일 구조 (제안)

```
GuruBox/
├─ main.py              # open_canvas(1600, 900) → game_framework.run(play_mode)
├─ game_framework.py    # run / change_mode / push_mode / pop_mode / quit, frame_time

├─ state_machine.py     # 이벤트 기반 상태 머신
├─ config.py            # 모든 수치(속도, 점프, 시간, 크기) 한곳에 모음
├─ sprite_data.py       # 제공 파일 (시트 좌표 + draw_box / draw_item)
├─ font_data.py         # 제공 파일 (글씨 시트 좌표 + draw_now / draw_number / draw_tip / draw_title)

├─ box.py               # 플레이어 박스 (상태 머신)

├─ dummy.py             # 몸통박치기 테스트용 허수아비
└─ resource/
   ├─ box_sheet.png
   ├─ item_sheet.png
   ├─ diary_frame.png   # 그림일기 틀 배경 (1600 x 900)
   ├─ font_sheet.png    # 손글씨 글씨 시트 (화면에 보이는 글씨는 모두 여기서)
```

- 객체는 공통으로 `update()`, `draw()`, `get_bb()`, `handle_collision(group, other)`를 가진다.
- 시간은 모두 `game_framework.frame_time`(초) 기준으로 계산한다 → 프레임 속도와 무관하게 같은 속도.

## 7. 기능 요구사항

### 7.1 박스 상태 머신

```
IDLE ──(←/→ 누름)──> WALK ──(뗌)──> IDLE
IDLE/WALK ──(Space 누름)──> CHARGE ──(Space 뗌)──> JUMP ──(착지)──> IDLE 또는 WALK
IDLE/WALK ──(Shift, 추격 구간, 테이프와 겹침)──> GET ──(시간 끝)──> IDLE
IDLE/WALK ──(Shift, 보스 구간, 쿨타임 아님)──> SLAM ──(돌진 끝)──> IDLE
```

- ←/→ 키는 누른 상태를 따로 기록해 두고(좌우 동시 입력 처리), 어느 상태에서든 방향 결정에 쓴다.
- 바라보는 방향(`face_dir`)은 마지막으로 누른 이동 방향. 왼쪽이면 좌우 반전해 그린다.

### 7.2 서 있기 (IDLE)

- idle 3장 반복, **7fps** (크레용 선 떨림)

### 7.3 걷기 (WALK)

- 속도 `WALK_SPEED = 310 px/s`
- 그림: jump 1~4를 **10fps**로 반복 + 그림만 위아래로 깡충 (`|sin|` 모양, 높이 `HOP_HEIGHT = 10px`)
- 깡충은 **그림 위치만** 움직이고 실제 위치·충돌 박스는 바닥에 그대로 있음

### 7.4 차지 점프 (CHARGE → JUMP)

- Space를 누르고 있는 동안 차지 시간 증가, 최대 `CHARGE_MAX_TIME = 0.6s`
- 차지 비율 c = 차지 시간 / CHARGE_MAX_TIME (0~1)
- 차지 중 이동 가능하지만 **느려짐**: 속도 × `CHARGE_SPEED_RATE = 0.4`
  - 이후 가속 지형 위에서는 감속하지 않음 → `box.on_accel_ground` 플래그만 만들어 두고 1주차엔 항상 False
- Space를 떼면 점프. 점프 높이 = `JUMP_MIN_H + (JUMP_MAX_H - JUMP_MIN_H) × c`
  - `JUMP_MIN_H = 48px`, `JUMP_MAX_H = 150px` (층 간격 180보다 낮게 → 점프 한 번으로 다음 층에 못 닿음)
  - 초기 속도 `vy = sqrt(2 × GRAVITY × 높이)`, `GRAVITY = 2400 px/s²`
- 점프 시작 시 가로 속도 = 그때의 이동 속도(차지 감속 적용된 값)
- 공중 좌우 조작 **조금 허용**: 가로 속도가 (입력 방향 × WALK_SPEED)를 향해 `AIR_ACCEL = 1080 px/s²`로 천천히 변함. 입력이 없으면 속도 유지.
- 그림: vy > 0 이면 jump 1~2(상승), vy ≤ 0 이면 jump 3~4(하강), 각 구간 10fps
- 착지: 발(y)이 바닥 높이 이하가 되면 바닥에 붙이고, 그때 ←/→가 눌려 있으면 WALK, 아니면 IDLE
- 공중에서 Space·Shift는 무시

### 7.5 테이프 줍기 (GET) — 추격 구간

- 플레이 칸 바닥에 **테스트용 테이프 3개**를 놓는다 (x = 500, 900, 1300). 그림 `tape`, 화면 크기 78 × 67 (0.6배)
- 테이프 위에서 살짝 떠서 위아래로 둥실 (진폭 4px, 1초 주기) — 선택 사항
- 조건: 박스 충돌 박스와 테이프 충돌 박스가 겹치고, 땅 위에 있고, 생명 칸이 꽉 차지 않았을 때(`TAPE_MAX = 5`) Shift
- 동작
  1. 박스가 그 자리에 멈춤, `TAPE_PICKUP_TIME = 0.5s` 동안 입력 무시
  2. 그림: get 1~3 (정면), 0.5초 동안 한 번 재생하고 마지막 장에서 멈춤
  3. 바닥 테이프는 사라지고, **TapePickupFx** 생성: 박스 머리 위로 0.25초 동안 떠오름(박스 위 약 60px) → 뒤에서 sparkle 2장이 8fps로 번갈아 반짝임 → 0.35초 동안 크기가 작아지며 플레이 칸 왼쪽 위의 다음 빈 생명 칸으로 날아감
  4. 날아가 도착한 순간 생명 +1 (생명 칸에 아이콘이 채워짐)
- 생명 칸이 꽉 찼으면 Shift를 눌러도 아무 일 없음(테이프는 그대로 남음)
- 시작 생명 `TAPE_START = 1`

### 7.6 몸통박치기 (SLAM) — 보스 구간

- 땅 위에서만 가능. Shift를 누르면 바라보는 방향으로 돌진
  - 거리 `SLAM_DIST = 130px`, 시간 `SLAM_TIME = 0.22s` (일정 속도), 끝나면 IDLE
  - 쿨타임 `SLAM_COOLDOWN = 0.5s` (돌진 끝난 뒤부터)
- 돌진 중에는 이동·점프 입력 무시
- 공격 판정: 돌진 중 박스 충돌 박스가 허수아비와 겹치면 **돌진 한 번에 1회만** 맞음
- 허수아비(Dummy): 플레이 칸 오른쪽(x = 1200) 바닥에 놓인 84 × 144 사각형(ph_dummy.png). 맞으면 0.15초 동안 살짝 흔들리고(좌우 ±4px), 머리 위에 맞은 횟수 표시
- 기획상 조건 참고: 이후 보스 쓸기 범위보다 돌진 거리가 짧아야 함 → 수치는 config에서 쉽게 바꿀 수 있게
- 추격 구간에서는 Shift = 테이프 줍기, 보스 구간에서는 Shift = 몸통박치기. 테이프·허수아비는 두 구간 모두 화면에 놓아 두되, 해당 구간에서만 반응

### 7.7 충돌 박스

- 그림보다 15~20% 작게. 박스 충돌 박스 = **가로 86, 세로 66**, 발 위치 기준 (x-43, y, x+43, y+66)
- 테이프 충돌 박스 = 그림 크기의 80%
- 게임 월드에 충돌 쌍으로 등록: `'box:tape'`, `'box:dummy'`

### 7.8 그림일기 화면 (hud.py)

- 맨 먼저 `diary_frame.png`를 (800, 450)에 그린다
- 지금·도망친 지·원고지 글자는 6장 표의 위치에 글씨 시트(`font_data.py` 함수)로 그린다
- 제목 "박스야, 도망쳐!"는 배경에 이미 있으므로 코드로 쓰지 않음
- 생명 칸 5개: 채워진 칸은 `tape_ui`를 1배(48 × 41)로, 빈 칸은 같은 그림을 `opacify(0.25)`로 흐리게
- 원고지 팁
  - 현재 구간의 팁 목록을 차례대로 보여 주고, `TIP_INTERVAL = 6초`마다 다음 팁으로 바꿈 (끝나면 처음으로)
  - 새 팁은 **한 글자씩 써지는 효과**: `TIP_CHAR_TIME = 0.05초`마다 한 칸씩 늘어남
  - `draw_tip(font, 문장, 52.5, 54, count)`로 그림, count = 팁이 바뀐 뒤 지난 시간 / TIP_CHAR_TIME
- B로 구간을 바꾸면 지금 칸 글자와 팁 목록이 바뀌고, 팁은 그 목록의 첫 문장부터 다시 써짐

## 9. 완료 기준 (체크리스트)

- [ ] `python main.py`로 1600 × 900 창이 뜨고, 그림일기 배경 위에 지금(`낮, 주택가`)·도망친 지(`0일 0시간 0분`)가 보인다
- [ ] 원고지 한 줄에 팁이 한 칸에 한 글자씩 써지고, 6초마다 다음 팁으로 바뀐다
- [ ] 박스가 바닥에 서서 idle 애니메이션이 반복된다
- [ ] ←/→로 걷고, 걸을 때 깡충 뛰는 모습이 보이며, 왼쪽으로 가면 좌우 반전된다
- [ ] 박스 바닥(발)이 모든 그림에서 같은 높이에 붙어 있다 (애니메이션이 바뀌어도 위아래로 튀지 않음)
- [ ] Space를 짧게 누르면 낮게(약 48px), 0.6초 이상 누르면 높게(약 150px) 뛴다
- [ ] 차지 중에는 눈에 띄게 느려지고, 박스가 납작해진다
- [ ] 공중에서 반대 방향키를 누르면 천천히 방향이 바뀐다 (확 꺾이지 않음)
- [ ] 상승 중엔 jump 1~2, 하강 중엔 jump 3~4가 보인다
- [ ] 추격 구간: 테이프 위에서 Shift → 0.5초 멈춤, 정면 그림, 반짝이며 떠오른 테이프가 생명 칸으로 날아가 채워진다
- [ ] 생명 칸이 5개로 꽉 차면 더 줍지 못한다
- [ ] B로 보스 구간 전환 → Shift로 짧게 돌진, 허수아비에 맞으면 횟수가 1씩 오른다 (한 번 돌진에 1회)
- [ ] 쿨타임 동안에는 몸통박치기가 나가지 않는다
- [ ] F1로 충돌 박스, R로 리셋이 동작한다
- [ ] 프레임 속도가 달라도 이동·점프 높이가 같다 (frame_time 사용)

## 10. 진행 방식

- 기능 하나씩 단계적으로: ① 골격·화면 틀 → ② 박스 서기·걷기 → ③ 차지 점프 → ④ 테이프 줍기 → ⑤ 몸통박치기 → ⑥ 디버그 키·정리
- 단계마다 실행해서 확인할 수 있는 상태로 커밋 (예: `feat: 박스 차지 점프`)
- 코드 주석은 한국어로 짧게
- 끝나면 완료 기준 체크리스트 결과와, 조정이 필요해 보이는 수치를 정리해서 알려준다
