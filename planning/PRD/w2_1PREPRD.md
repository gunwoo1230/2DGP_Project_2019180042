## 1. 배경
- `week1_4`까지 된 것: 생명 칸 바닥 가운데, 해 일직선, 화면 밖 경비원 표시, 기절 규칙(한 층 아래 이하), 층별 속도

- 기획 변경 (11/16)
  1. **건물 양식**: 넓은 건물 2종, 좁은 건물 2종, 경사 지붕 건물 2종을 그린다. 타일마다 양식을 랜덤으로 골라 반복 느낌을 줄인다
  2. **배수관·전봇대는 건물과 함께**: 배수관 = 넓은 건물 + 왼쪽 벽 배수관, 전봇대 = 좁은 건물 + 왼쪽 빈터 전봇대. 건물 양식은 따로 고른다
  3. **창문**: 넓은 건물 3개, 좁은 건물 2개 고정. 가로 위치와 높이는 조금씩 랜덤
  4. **발디딤 규칙**: 한 층(180)을 점프 두 번으로 — 층 중간 높이 1개 + 층 높이 1개 (배수관 300·390·480, 전봇대 300·390·480·570)
  5. **조각(chunk) 랜덤 맵**: 짧은 타일 묶음을 배열로 정의하고 랜덤으로 이어 붙임, 묶음 안의 `climb` 자리는 배수관 또는 전봇대 타일
  6. **빨랫줄**: `gap`에서 2층(창틀)에 있으면 앞 건물과의 넓은 틈 때문에 무조건 떨어진다 → `accel` 마지막 창문과 `gap` 첫 창문을 **빨랫줄**로 잇는다. 박스는 빨랫줄 위를 걸을 수 있고, 가속 지붕처럼 **가속**을 받는다
- 진짜 건물 그림은 사용자가 새로 그리는 중이다. **이번에는 그림 없이 지금 임시 그림(사각형)으로 발판 랜덤만 적용**한다. Tiled 전환과 그림 교체는 그림이 준비되면 다음 단계에서 한다.

### 5.2 창문 랜덤 (MAP-9)
| 값 | 기본값 | 뜻 |
|---|---|---|
| `WINDOW_W` | 90 | 창틀 발판 길이 = 창문 폭 (그림도 창문 폭 90, 2배 그림에서는 180) |
| `WINDOW_GAP_MIN` | 50 | 창틀 사이 최소 간격 (발 폭 40보다 넓어 걸어서 못 건넘, 점프해야 함) |
| `WINDOW_YS` | 380, 385, 390, 395, 400, 405 | 창틀 높이 후보 (창문마다 따로 고름) |
| `WINDOW_H` | 70 | 임시 창문 그림 높이 (창틀 위로) |
- 순서
  1. 개수 `n` = 타일의 창문 수 (넓은 3, 좁은 2)
  2. 남는 폭 `free = 구역 폭 - n × WINDOW_W - (n - 1) × WINDOW_GAP_MIN` (넓은 110, `gap` 50, `pole` 90)
  3. `free`를 `n + 1`조각으로 랜덤하게 나눠 (0 ~ free 사이 난수 n개를 정렬) 창문 앞·사이·뒤 빈칸에 더한다 → 창문끼리 항상 50 이상, 구역 밖으로 안 나감
  4. 창문마다 높이를 `WINDOW_YS`에서 고른다
  5. 창문 하나 = 발판 `('ledge', x, y, x + WINDOW_W, y)` + 그림 (창문 사각형은 창틀 위 `y ~ y + WINDOW_H`, 좌우 10씩 안쪽)
- 높이 범위 이유: 405 + 70 = 475라 지붕 아래(550)에 들어가고, 380이면 창틀 층 최소 높이(375)보다 위

### 5.3 배수관 (`pipe` 타일, MAP-4)
| 값 | 기본값 | 뜻 |
|---|---|---|
| `PIPE_W` | 16 | 임시 배수관 굵기 |

### 5.5 층 판정 수정 (BOX-8)

### 5.6 빨랫줄 (MAP-12)
- **왜**: `accel` 다음 `gap`은 건물 사이가 넓어(지붕 끝 560 → 다음 벽 840) 2층 창틀에서는 건널 곳이 없어 무조건 도로로 떨어진다
- **어디에**: 이웃한 두 건물 사이. 앞 건물의 **마지막(오른쪽) 창문**과 다음 건물의 **첫(왼쪽) 창문**을 잇는다
  - **항상**: `accel` → `gap` 사이 (gap 타일마다 1개)
  - **가끔**: 그 밖의 이웃한 건물 사이에 `CLOTHESLINE_CHANCE = 0.3` 확률. 2층으로 쭉 달리는 길이 가끔 생긴다
    - 앞 타일: `basic` `pipe` `accel` `gap` `pole` (창문이 있는 건물)
    - 다음 타일: `basic` `pipe` `accel`만. `pole`은 빼고(전봇대 못과 겹침, 이미 오르는 곳), `start`는 창문이 없어 뺀다
  - 정하는 순서: 모든 타일(양식·창문)을 만든 뒤, 맵 왼쪽부터 이웃한 두 타일마다 차례로 같은 시드 난수로 정한다 → 같은 시드면 같은 빨랫줄
- **발판**: `('line', 앞 창틀 오른쪽 끝 x, 앞 창틀 y, gap 첫 창틀 왼쪽 끝 x, gap 첫 창틀 y)` (월드 좌표)
  - 두 창틀의 높이가 다르면(380 ~ 405) 살짝 기운 선분 → 가속 지붕처럼 `surface_y`로 처리
  - 창틀 끝과 바로 이어지므로 창틀 → 빨랫줄 → 창틀을 **걸어서** 건넌다
  - 길이는 `gap` 앞 약 320 ~ 470, 일반 건물 사이 약 120 ~ 300
- **가속**: 빨랫줄 위에서 **오른쪽으로 갈 때** 가속 지붕과 같은 배율(`ACCEL_RATE` 1.5), 차지 중에도 감속 없음 (가속 지붕과 같은 규칙)
  - 수치를 따로 조정할 수 있게 `config.LINE_RATE = 1.5`를 두고, 가속 판정에서 발판 종류에 맞는 배율을 쓴다
- **층**: 높이 380 ~ 405 → 창틀 층 (지붕에서 빨랫줄로 내려와도 기절 안 함)
- **만드는 곳**: 두 타일에 걸치므로 타일 하나를 만들 때가 아니라 **`Level.load`에서 모든 타일을 만든 뒤** 추가한다
- **그림(임시)**: `ph_rope.png`를 선분을 따라 두께 4로 (`draw_slope`와 같은 방식, 윗면이 발판 선). 진짜 그림은 처지는 줄 + 빨래 — 판정은 직선 그대로

## 6. 낮 맵 만들기 (MAP-3)

### 6.1 조각 배열 (`map_data.py`)
- 조각 = 타일 이름 목록, `climb` = 오르는 도구 자리 (`pipe` 또는 `pole`)
```python
EASY = [['basic', 'climb', 'basic'],
        ['basic', 'basic', 'climb', 'basic'],
        ['basic', 'accel', 'basic', 'climb']]
NORMAL = [['basic', 'accel', 'gap', 'climb'],
          ['climb', 'basic', 'accel', 'gap'],
          ['basic', 'climb', 'accel', 'basic', 'basic']]
HARD = [['accel', 'gap', 'accel', 'gap', 'climb'],
        ['basic', 'accel', 'gap', 'basic', 'accel', 'gap', 'climb'],
        ['climb', 'accel', 'gap', 'basic', 'accel', 'basic']]
```
- 조각을 쓸 때 지킬 것 (조각을 새로 만들 때도)
  - `gap`은 `accel` 바로 다음에만 (가속해야 넓은 틈을 건넘)
  - `climb`은 `accel`과 `gap` 사이에 넣지 않는다
  - 조각마다 `climb` 1개 이상 → 도로에 떨어져도 가까이에 오를 곳이 있음

3. 조각의 이름을 차례로 넣는다. `climb`은 반반 확률로 `pipe` 또는 `pole`로 바꿔 넣는다
4. 건물이 **60개가 되면 거기서 끝** (조각 나머지는 버림) → 맵은 지금처럼 61칸
5. 결과 예 (시드 1): `start, basic, pipe, basic, basic, accel, basic, pipe, basic, basic, pole, …`
- 난수는 `random.Random(seed)` 하나로 맵·양식·창문을 모두 만든다 → 같은 시드면 같은 맵

### 6.3 고정 맵

- `BOSS_ARENA = ['start', 'start', 'start']` 그대로

## 7. 시드와 디버그 키
| 키 | 동작 |
|---|---|
| `R` | **새 시드**로 처음부터 (새 맵) |
| `T` | **같은 시드**로 처음부터 (같은 맵 다시 — 버그 재현용) |
| 잡혀서 다시 시작 | 새 시드 |
| `M` | 낮 맵 ↔ `TEST_MAP` (지금처럼) |
| `N`, `E`, `G`, `1 2 3`, `F1`, `B` | 지금처럼 |
- 맵을 만들 때마다 콘솔에 `seed = 12345` 출력
- 시드 기본값: 시간 등으로 랜덤. `config.FIXED_SEED = None` (숫자를 넣으면 항상 그 시드 — 시험용)

## 8. 그리기 (임시)
- 그리는 순서: 도로 → 벽(양식별 임시 그림) → 창문 그림 → 배수관·전봇대 → 발판(지붕·창틀·받침·가속 지붕) → 빨랫줄
- 빨랫줄은 두 타일에 걸치므로 타일 그리기가 아니라 레벨이 따로 그린다 (화면 밖이면 건너뜀)
- `F1` 디버그 선에서 빨랫줄은 가속 지붕처럼 주황
- 발판 임시 그림은 지금처럼 윗면이 발판 선에 오도록 두께만큼 아래로
- `F1` 디버그 선은 지금처럼 모든 발판 (창틀이 랜덤 높이에 그려지는지 확인)

## 9. 완료 조건
- [ ] 실행할 때마다 낮 맵이 달라진다 (콘솔 시드가 바뀜), `T`로 같은 맵이 다시 나온다
- [ ] 넓은 건물(`basic`·`pipe`)은 `wide_a`/`wide_b`, 좁은 건물(`gap`·`pole`)은 `narrow_a`/`narrow_b` 양식이 섞여 나온다
- [ ] 창문 개수는 넓은 3, 좁은 2이고, 가로 위치와 높이(380 ~ 405)가 건물마다 다르다
- [ ] 창틀 사이는 걸어서 못 건너고 점프해야 한다 (간격 50 이상)
- [ ] 배수관이 건물 왼쪽 벽 바깥에 붙고, 받침 300 → 390 → 480 → 지붕을 **점프 두 번에 한 층**으로 오른다
- [ ] 전봇대: 도로에서 못 300 → 390 → 480 → 570으로 오르고, 390에서 창틀, 570에서 지붕으로 건너간다
- [ ] `gap`은 항상 `accel` 다음에 나온다
- [ ] `gap` 앞마다 빨랫줄이 있고, `accel` 2층 창틀에서 빨랫줄을 걸어 `gap` 첫 창틀까지 떨어지지 않고 건너간다
- [ ] 빨랫줄 위에서 오른쪽으로 갈 때 빨라지고(가속 지붕과 같은 느낌), 왼쪽으로는 보통 속도다
- [ ] 일반 건물 사이에도 가끔(약 30%) 빨랫줄이 생기고, `pole` 앞과 `start` 옆에는 생기지 않는다
- [ ] 지붕 → 창틀(380 ~ 405) 내려오기는 기절 없음, 지붕 → 300 받침·도로는 기절
- [ ] 점수·해·낮 끝은 지금처럼 동작한다 (61칸)
- [ ] `TEST_MAP`(`M`)과 보스 무대(`B`, 낮 끝)는 지금처럼 동작한다
