# 박스야, 도망쳐! — 2주차_1 커밋 계획 (w2_1PRD)

> `week2_1` 브랜치에 실제로 올릴 커밋을 순서대로 정리한 문서입니다.
> 동작·수치의 원본은 [`w2_1PREPRD.md`](w2_1PREPRD.md) (11/16 수정판)이고, 이 문서는 **무엇을 어떤 순서로 커밋할지**를 다룹니다. `§5.6`은 PREPRD의 5.6장을 뜻합니다.

- 작업 시점: 11/16 ~
- 목표: 낮 맵을 매 판 새로 만든다. 조각을 랜덤으로 이어 붙이고, 타일마다 건물 양식과 창문(창틀 발판) 위치·높이를 랜덤으로 정하고, 배수관·전봇대 발디딤을 새 규칙(한 층 = 점프 두 번)으로 바꾸고, `accel` → `gap` 사이 2층을 빨랫줄로 잇는다
- 그대로인 것: 타일 6종·폭 600, 맵 61칸, 점수(최고 도달 타일 × 10분), `day.py` (PREPRD §4)
- 범위 밖: 진짜 건물·창문·배수관·전봇대·빨랫줄 그림, Tiled 맵, 테이프 층별 배치, 물웅덩이·창문 방해 요소·비둘기, 밤 맵, 날마다 난이도 (PREPRD §2)

## 2. PREPRD와 다르게 잡은 부분, 결정한 것

### 결정한 것 (PREPRD에 정해지지 않았던 항목)

| # | 질문 | 결정 |
|---|---|---|
| Q1 | 타일 하나를 만든 결과는 어떤 모양인가? | `tiles.py`의 `build_tile(name, rng)`가 타일 안 좌표의 dict를 돌려줌: `name`, `style`, `walls`, `windows`(창문 그림 사각형), `pegs`(받침·못 하나씩, Q16), `deco`(배수관·전봇대 기둥 사각형), `platforms`(발판 선분). `Level`은 `(tile, left)` 목록으로 들고, 발판만 왼쪽 끝만큼 옮겨 월드 좌표로 바꿈. `draw_tile(tile, left)`는 만든 결과를 그대로 그림 |
| Q2 | 난수를 쓰는 순서는? | 참고 구현과 같게: **맵 목록** → 타일을 왼쪽부터 (**양식** → 창문 자르는 점 `n`개 → 창문마다 높이) → **빨랫줄**(왼쪽부터 이웃한 두 타일마다, `gap` 앞이면 난수를 쓰지 않음). 창문 가로 위치는 `round`. 같은 시드면 참고 구현과 **숫자까지 같은 맵**이 나와 비교 스크립트로 확인 가능 |
| Q3 | 창틀 층 최소 높이 375는 어디에 두나? | `config.LEDGE_FLOOR_Y = 375`를 새로 두고 `FLOOR_YS = (ROAD_Y, LEDGE_FLOOR_Y, ROOF_Y)`. `LEDGE_Y = 390`은 디버그 키 2에 남김 (§5.5). 받침·못 높이는 `PIPE_PEGS_Y`, `POLE_PEGS_Y`로 따로 둠 |
| Q4 | 지울 것 | `tiles.py`의 `PEGS_Y`, `basic_ledges`, 타일마다 고정된 창틀, 배수관 안쪽 위치(82 ~ 98), 전봇대 그림 높이 600 (§5.3, §5.4) |
| Q5 | 양식 그림은 어떻게 고르나? | 타일 정의에 `styles` 후보, `build_tile`이 `rng.choice`로 골라 `style`에 넣음. 그림은 `images['wall_' + style]` (`ph_wall_<style>.png`). `start`는 벽이 없어 양식도 없음 (`None`) |
| Q6 | 빨랫줄은 어디에 들고 있나? | `Level.load`에서 모든 타일을 만든 뒤 `make_lines(rng)`로 만들어 `self.lines`에 두고 `self.platforms`에도 넣음 (밟는 판정은 다른 발판과 같음). 그리기는 `Level.draw`가 타일을 다 그린 뒤 따로 (§8) |
| Q7 | 빨랫줄 가속은 box에서 어떻게? | `config.ACCEL_RATES = {'accel': ACCEL_RATE, 'line': LINE_RATE}`. `check_ground`에서 `on_accel_ground = platform.kind in config.ACCEL_RATES`, `walk_speed()`는 `floor_speed × ACCEL_RATES[ground.kind]`. 차지 중 감속 없음, 점프 속도 유지도 가속 지붕과 같은 코드를 탐 |
| Q8 | 빨랫줄 위 속도는? | 배율은 가속 지붕과 같은 1.5지만 빨랫줄은 **창틀 층**이라 `330 × 1.5 = 495` (가속 지붕은 지붕 층 `350 × 1.5 = 525`). PREPRD "같은 배율"을 그대로 따른 결과 |
| Q9 | 빨랫줄 화면 밖 건너뛰기 | 두 끝이 모두 화면 왼쪽 밖이거나 모두 오른쪽 밖(`DRAW_MARGIN` 포함)이면 건너뜀 |
| Q10 | `F1` 색 | 발판 종류가 `ACCEL_RATES`에 있으면 주황 (가속 지붕·빨랫줄), 나머지 빨강 |
| Q11 | 맵 만들기 설정값 이름 | `config.DAY_BUILDINGS = 60`, `CHUNK_LEVELS = (20, 40)`(건물 수가 이 값보다 작으면 쉬움 / 보통 / 그 밖은 어려움), `CLIMB_TILES = ('pipe', 'pole')`에서 `rng.choice`. 참고 구현이 `choice`를 써서, 확률값(`random() < 0.5`)으로 바꾸면 같은 시드의 결과가 달라지므로 이 방식으로 둠 (11장 확인 4를 바꿀 때는 후보 목록을 바꿈) |
| Q12 | `R`·`T`·잡힘으로 다시 시작할 때 맵 종류는? | **지금 맵 종류(낮 맵 / `TEST_MAP`) 그대로**, 시드만 새로(R·잡힘) 또는 그대로(T). 지금은 `R`이 항상 낮 맵으로 돌아가지만, `TEST_MAP`에서 양식·창문만 바꿔 보려면 종류를 유지하는 편이 편함. 보스 무대(`B`로 들어간 빈터)에서 다시 시작하면 지금처럼 낮 맵 |
| Q13 | `M`으로 맵을 바꿀 때 시드는? | **지금 시드 그대로.** 낮 맵 ↔ `TEST_MAP`을 오가도 돌아오면 같은 낮 맵이고, 어느 쪽에서든 `T`로 재현 가능 |
| Q14 | 보스 무대(`start` 3칸)의 난수 | 양식·창문·빨랫줄이 없어 난수를 쓰지 않음. 시드도 출력하지 않음 |
| Q15 | 맵 종류 비교 | 지금은 `level.names == DAY_MAP`으로 비교하지만 낮 맵이 매번 달라지므로 `play_mode`에 `map_kind`(`'day'` / `'test'`)를 둠 |
| Q16 | 받침·못은 어떻게 들고 있나? (11/16 사용자 결정) | 나중에 받침·못도 창문처럼 하나씩 따로 그릴 예정이라, **창문처럼 하나씩** 둠: `tile['pegs']`에 `(x0, y, x1)` 하나가 발판 하나 + 그림 하나. 발판 목록은 창틀·받침·못을 모아 만들므로, 받침 하나를 빼면 발판과 그림이 함께 빠짐 |
| Q17 | 빨랫줄이 배수관 받침과 겹치면? (11/16 사용자 결정) | **겹치는 받침을 뺀다.** 빨랫줄이 `pipe` 타일로 이어지면 그 타일의 **390 받침**을 뺌 (줄 높이 380 ~ 405와 겹치는 것은 390뿐, 300·480은 그대로). 빨랫줄이 받침 자리(x -20 ~ 40)를 지나가므로 300 받침 → 줄 → 480 받침으로 그대로 오를 수 있음 (각 75 ~ 105, 점프 최대 150 이내). `pole`은 `LINE_TO`에 없어 못이 빠지는 일은 없음 |

## 3. 파일 구조

```
project/
├─ config.py     # 수정: WINDOW_*, PIPE_*, POLE_PEGS_Y, LEDGE_FLOOR_Y, FLOOR_YS, LINE_RATE, ACCEL_RATES,
│                #       CLOTHESLINE_CHANCE, LINE_FROM, LINE_TO, DAY_BUILDINGS, CHUNK_LEVELS, CLIMB_TILES, FIXED_SEED
├─ tiles.py      # 수정: 타일 정의(벽·지붕·창문 구역·창문 수·양식 후보·배수관/전봇대), build_tile(name, rng),
│                #       창문·배수관·전봇대 만들기, draw_tile(tile, left). PEGS_Y·basic_ledges·고정 창틀 삭제
├─ map_data.py   # 수정: EASY·NORMAL·HARD 조각, make_day_map(rng). DAY_PATTERN·DAY_MAP 삭제, TEST_MAP 그대로
├─ level.py      # 수정: load(names, rng), 만든 타일 보관, 빨랫줄 만들기·그리기, F1 색
├─ box.py        # 수정: 가속 판정에 빨랫줄 (ACCEL_RATES). 층 판정은 config.FLOOR_YS로 따라옴
└─ play_mode.py  # 수정: 시드 관리(새 시드 / 같은 시드), 맵 종류 유지, T 키, 시드 출력
resource/placeholder/   # 새 임시 그림: ph_wall_{wide,narrow,accel}_{a,b}.png, ph_window.png, ph_rope.png
```

`Level`이 들고 있는 것 (C01 이후, `lines`는 C08 이후)

| 이름 | 내용 |
|---|---|
| `names` | 타일 이름 목록 |
| `tiles` | `(tile, left)` 목록 — `tile`은 `build_tile`의 결과 |
| `lines` | 빨랫줄 발판 목록 (월드 좌표) |
| `platforms` | 모든 발판 (월드 좌표, 빨랫줄 포함) |
| `right` | 마지막 타일 오른쪽 끝 (그대로) |
